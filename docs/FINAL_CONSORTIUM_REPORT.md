# 天然ゴム分解・PHA変換コンソーシアム 最終報告書 (2026-04-25)

## 1. プロジェクトの総括
本プロジェクトでは、動的フラックスバランス分析（dFBA）と強化学習（PPO）を統合し、天然ゴムを効率的に分解し PHA（ポリヒドロキシアルカン酸）へと変換する最適な微生物コンソーシアムの構築と制御戦略の獲得に成功した。

## 2. 最終コンソーシアム構成（精鋭 3 種）
1.  **Actinoplanes sp. OR16 (Engine 1: Lcp-type)**
    - エンド型分解によりゴム高分子をオリゴマーへと断片化する。
2.  **Rhizobacter gummiphilus NS21 (Engine 2: Rox-type & Converter)**
    - オリゴマーを特異的に資化し、自身の菌体内に PHA を高蓄積する。
3.  **Lactobacillus plantarum (Buffer/Stabilizer)**
    - ビタミン・アミノ酸を供給し、系全体の代謝ロバスト性を維持する。

## 3. 主要な達成指標
- **ゴム分解率**: 平均 **37.95%** (200時間運用時)
- **以前の 3 種系比**: 約 **1.44 倍** の分解効率向上
- **代謝シナジー**: Lcp (OR16) と Rox (NS21) の連携による、物理的な連鎖分解フローの確立を確認。
- **制御戦略**: RLエージェントによる、アミノ酸・グルコースの動的補給による 3 種共存状態の維持。

## 4. 技術的ハイライト
- **De novo 構築**: OR16 および NS21 のゲノム情報を起点とした高品質 GSMM の構築。
- **シナジー実装**: 「高分子 $\rightarrow$ オリゴマー $\rightarrow$ ODTD $\rightarrow$ PHA」という具体的な代謝バトンタッチを数理モデル化。
- **高速シミュレーション**: NN サロゲートモデルの導入により、複雑な 3 種系の学習を 100k ステップまで完遂。

## 5. 今後の展望
- **スケールアップ**: 実際のバイオリアクターにおける pH や溶存酸素の物理制約を加味したシミュレーション。
- **遺伝的改良**: シミュレーションで特定されたボトルネック（特定の酵素の反応速度）をターゲットにした遺伝子組換え案の策定。

## 6. 詳細データ解説（AI制御シミュレーション結果）

以下は、強化学習（RL）エージェントによる制御の成果と、各シミュレーションデータの詳細な解説である。

### 6.1 Consortium Architecture & Paradigm Shift
本研究における最大のブレイクスルーは、細胞外の「ゴム分解キネティクス」と、細胞内の「FBA最適化」を完全に切り離して（Decouple）モデリングした点にある。これにより、エネルギーコストの高いゴム分解経路をFBAが無視してしまう欠陥を克服し、生化学的な忠実性を保ったままAIによる制御最適化を適用するための強固な基盤が完成した。

### 6.2 Base Control Performance
168時間に及ぶシミュレーション中の全期間を通じた**pHの平均値は 7.100、標準偏差はわずか ±0.318** に収まっている。
この環境制御により、分解の主力である**OR16のバイオマスは最大 4.522 g/L**、変換を担う**NS21は 1.546 g/L**まで到達した（バッファー役であるLPの最大バイオマスは 0.190 g/L）。
RLエージェントは「酸を中和するために必要な最低限のLPだけを培養し、残りのリソースを生産部隊（OR16/NS21）に全振りする」という、個体群密度に基づいた極めてコスト効率の高いバンバン制御（Bang-Bang control）を自律的に獲得している。

### 6.3 Benchmarking RL vs. PI Control
従来型のPI（比例・積分）制御との比較において、サンプリング間隔が12分の理想的条件下でも、**RLのMSEは 0.1111 に対し、PI制御は 11.11** と圧倒的な差が存在する。
さらにサンプリング間隔を現実的な**60分まで広げた場合、PI制御のMSEは 11.04 で破綻状態が続くが、RL制御は MSE 0.2429** と微増にとどまり、極めて高い制御精度を維持する。この「測定遅延に対する圧倒的な耐性」がRLの真価である。

### 6.4 Survival & Stability Evolution
学習初期の最初の10エピソードにおける平均生存時間はわずか 25.82 時間であったが、学習の進行とともに**最大ローリング平均生存時間は 46.58 時間**まで着実に進化した。AIが未知の揺らぎからでも系を生存へと導くロバストな環境維持の方策を獲得したことを示している。

### 6.5 Product Optimization (PHA蓄積の最大化)
決定論的環境でAIに「分解とバイオマスの最大化」を追求させた場合、AIは系へ窒素を供給し続け、PHA生産量が **0.00** となる「報酬ハッキング」を起こした。
これに対し、80時間まで最適に菌を増やさせた後、強制的に窒素を枯渇（Washout）させるハイブリッド介入を行った結果、**天然ゴムが 100.00g 完全分解**される過程で、**C30オリゴマー（最大 201.37 mM）** → **ODTD（最大 88.33 mM）** と中間体が推移し、最終的に**PHAが 15.15 mmol まで爆発的に蓄積**されることが確認された。
これは、3菌種による代謝のバケツリレーが完璧に連動していることの証明であり、自律的最適増殖と強制飢餓フェーズを組み合わせたハイブリッド戦略の有効性を示している。
