# 培養モデル監査：修正前の問題一覧（2026-09-08）

ユーザー指定の順序に従い、この一覧を先に作成し、その後に修正する。対象は OR16・NS21・Pf のGEM、細胞外ゴム分解、培地・酸素・pH・菌体・PHAの動態、培養器、RLへの入出力・評価、教師データの来歴。GPU内部の全アルゴリズムを再監査したものではない。

**現状の数値出力を実培養で検証済みの予測、または安定3種共生の証明として扱えない。実装上の不整合を直すことと、生理パラメータを実測で校正することは別である。**

P1：生産量・種間順位・物質収支を変え得る。P2：制御・評価・解釈を誤らせる。`修正`は根拠ある実装変更、`仮定明示/要検証`は値や反応を捏造せず残す課題。

## A. 数値計算・物質会計

## B. 生物学・実験根拠

|---|---|---|---|

|B03|P1|Pf由来B12を受け取るOR16/NS21側の明示的な共有インターフェース/需要がない。OR16には一部前駆体があるが供給利益の証明ではない。PfのB12関連反応にも未確定GPR。|B12による3種共生を現在のモデルから主張しない。受容・依存・代替酵素を確認してからモデル化。|

|B05|P1|OR16/NS21のATPM下限0、Pf ATPase下限0。pH7でμ0の菌がエネルギー維持なしで残る。|安定共存の評価を無効と明示。維持ATP、死滅、継代/希釈を実測で導入。死滅率を捏造しない。|

|B07|P1|glucose/YEが0でも背景アミノ酸・ビタミン・核酸塩基がC/Nを供給（utils）。|投入成分・量を保存。総PHAをゴム由来PHAと同一視しない。|

## 修正順序と再評価の条件

1. 修正前のソース・進行中結果を保存。この文書を修正前リストとして固定し、対応結果は別文書に記録。
2. A01–A13のうち再現可能な不整合を、版を分けた監査用参照経路で修正する。酸素の割当と生理応答は仮定を残して透明化し、物質収支検証と刻み感度を加える。
3. RL費用/reset/評価・モデル選択・教師のsource整合を修正し、旧教師を修正版の正解として使わない。
4. 実測を要するB項目は未解決として残し、モデルの有効範囲を出力に保存する。実データがない箇所を「修正済み」とはしない。
5. その後、3種共生の比較を修正版で再開する。まず基準/低kLaの対照、NS21単独・別2種・Pf代謝停止の反実仮想を確認する。陽性だけを選ばず、接種比・仮定・数値刻みの影響を分ける。

主な確認元：`src/dfba_simulator.py`、`src/resolved_dfba.py`、`src/one_l_jar.py`、`src/rl_environment.py`、`src/ppo_agent.py`、`src/utils.py`、`src/graph_training_collection.py`、`scripts/analysis/screen_propionibacterium_helper.py`、GEM curation scripts、対応tests。
