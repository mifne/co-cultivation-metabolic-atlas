## Pf は増えるか、何が律速するか
- どちらの設定でも、Pf は実質的に増えない。 ／ ピークは初期の 1.02 倍（k10）と 1.39 倍（k2、以前の監査と一致）。24 h 時点は 0.27 倍と 0.37 倍。
- k10: Pf が取れる lactate は 3% だけで、μ は 2 h で 0.0026/h に落ちた。7 h に NH4 が枯渇すると、μ は −0.01（基礎死亡率）になった。
- k2: 12 h までは μ 0.020–0.046/h で増えた。
- 共通: 12 h に lactate の供給が止まると maintenance の不足率が 1 になり、死亡率 0.1098/h で 12→24 h に約 0.27 倍に減った。
- 以前の監査の「OR16 が lactate の約 78% を取る」は、この条件では再現しなかった（56% と 29%）。

## 結論に効く差と無視できる差
- 無視できる差: 菌体（≤0.5%。k2 の NS21 のみ +1.7%）、Pf の運命、k10 の PHA、CO2（≤0.9%）、計算時間
- 効く差 ／ OFF では Pf の C の 17–24% が消える。硫黄源は H2S sink から SO4 に変わる。 ／ k2 の ON では formate が 0.34 mM 溜まり、12 h の NH4 が 0.34 から 0.10 mM に下がる（OR16 の NH4 排出が 0.53 から 0.38 に減るため）。PHA は −2.5%。 ／ これらは交換や台帳の主張には効くが、Pf の増殖についての結論は変えない。
- 検証していないこと ／ 菌体と PHA を含む完全な C 収支と、種ごとの取り込みの時系列（記録は累計だけ） ／ kLa 50、他の供給プロファイル、refine の dt、two arm、legacy simulator、生物学的な妥当性
