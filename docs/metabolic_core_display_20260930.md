# 中心代謝を起点とする表示の選定・実装方針（2026-09-30）

## デフォルトに採用する範囲

栄養を選ぶ前から、各菌種のモデルに実在する中心炭素代謝の骨格を表示する。
KEGGの分類（[解糖系・糖新生 / TCA / PPP](https://www.genome.jp/kegg/pathway.html)）を経路の整理に用いるが、反応・化合物・方向はローカルGEMの量論と上下限を正とする。

|範囲|採用理由・表示|
|---|---|
|解糖系・糖新生の共通骨格|糖由来の入口とピルビン酸への連絡を示す。不可逆段階の逆向きを勝手に描かない。|
|酸化的・非酸化的ペントースリン酸経路|糖の分岐、還元力・生合成前駆体の入口を示す。補助基質は詳細切替で確認可能。|
|ED経路|登録された反応のみ採用。NS21のPFK欠落を架空のEMP経路で埋めない。|
|ピルビン酸→アセチルCoA、TCA関連反応|有機酸・アミノ酸が合流する骨格。TCA代謝物は円周上に固定し、欠落反応で輪を閉じない。|

PHA、プロピオン酸生成、アミノ酸・核酸合成全体は初期表示に詰め込まず、既存の候補選択から追加する。これは重要性や活性の否定ではなく、初期表示の粒度の選択である。

## 実モデルで確認した差

- OR16: PFKあり。ACONTによるcitrate→isocitrateを採用する（ACONTbがない）。succinate→fumarateには正方向を許すFRD2rppを用いる。SUCD1は登録上逆方向のみなので酸化方向の代わりに使わない。EDDは登録なし。
- NS21: PFKおよびGNDなし。EDD・EDAあり。ACONTによるTCAの代表区間を採用する（ACONTa/bも別候補には残す）。
- Pf: ModelSEED系のIDを個別に対応づける。PGK・PGM・PYKなどのモデル上の符号は表示したい方向と一致しないため、量論から決める。isocitrate→oxalosuccinate→2-oxoglutarateは2段階。F1,6BP→F6Pには登録されたPPi生成反応を表示し、通常のFBP加水分解酵素とは同一視しない。ピルビン酸・2-oxoglutarateの酸化的脱炭酸はモデルにあるferredoxin依存反応を用いる。標準的なSUCOASは登録されていないため、succinyl-CoA→succinateをATP生成反応として捏造しない。

これらはモデルの登録状況であり、実細胞での欠損・活性を実証した結論ではない。

## 栄養からの接続

1. 初期表示は中心代謝のみ。複数の外部成分をチェックして追加する。
2. 選んだ成分を取り込む実在の交換反応から、許容方向の輸送・変換反応を辿り、表示中の中心代謝物へ接続する。
3. 水・ATP・NAD・CO2・CoA等を通る見かけの短絡、Biomass・需要反応、細胞外へ戻る迂回は経路探索に使わない。炭素源は炭素を含む代謝物間を辿る。窒素・無機成分は取り込みと直接利用を区別して表示する。
4. 自動選択は短い構造上の接続候補。追加必須基質も量論に保持し、共通pFBAでの流れ・個別の成立判定とは明確に区別する。原子追跡や実培養での成立保証ではない。
5. 未添加の成分は仮想起点と明示し、表示追加だけではFBAの培地条件を変更しない。必要な濃度変更は既存の培地編集で適用する。
6. 接続不能の場合は入口と理由を表示する。中心代謝の位置は成分追加では動かさない。

## 保存・検証

旧表示の自動保存は退避し、新しい中心代謝表示へ移行する。旧表示は明示的に復元可能にする。以後は中心代謝モード・栄養起点・配置・省略・培地条件を保存する。
検証対象は3種の量論・方向、代表的な糖/アミノ酸の接続、補因子による短絡除外、欠落区間、TCA配置の維持、追加・保存・再読込みである。

## 実装結果

- 初期表示: OR16 28反応、NS21 27反応、Pf 27反応。未登録・方向不適合の区間は画面の「採用経路と未登録の区間」で確認可能。
- TCA代謝物は円周、解糖系は横一列、PPPは格子状に配置。解糖系・PPP・TCAの拡大ボタンを追加。補助基質は切替で表示、反応詳細では常に全量論を保持。
- グルコースは3種ともG6Pへ接続。乳酸は3種ともピルビン酸へ接続。OR16/NS21のグルタミン酸は輸送と脱水素反応を介して2-oxoglutarateへ接続。NH4とO2は中心炭素骨格へ偽の矢印を作らず、輸送または実際の補助基質としての接続まで表示する。
- 水・ATP等に加えCO2・CoA・電子伝達補因子を経由する接続短絡を除外。無機成分は同一組成の輸送を辿る。経路は最大10反応・探索6000状態を上限にした構造上の候補であり、欠落・制限は接続不能表示にする。
- 栄養の選択はFBA条件を変更しない。未添加成分は仮想起点。適用濃度を変えるには「計算・保存・詳細設定」の培地編集を利用する。
- 旧自動保存は端末内の退避キーへ保存し、復元ボタンを提供。モデルが一致する旧条件は培地濃度を引き継ぐ。新しい表示の起点・座標・補助基質表示を保存・復元する。
