## 1. 調査で分かったこと（前提の修正）

- 元論文モデル（Machado 2020, `P_sherm_model.xml`）は区画を1つしか持たない SBML（全 1197 代謝物が `c`）。`S_<id>_ext` は**細胞外の化学種**で、区画ラベルだけが `c` になっている。
- 各 `S_<id>_ext` は、モデル自身の輸送反応ですでに細胞質の `S_<id>_c0` とつながっている（例: `rxn05467_c0` CO2 拡散、`rxn10159_c0` コハク酸:フマル酸アンチポーター、`rxn05469_c0` ピルビン酸 H+ 共輸送、`rxn05581_c0` グリセロール拡散）。172 本すべてに相手反応があり、孤立した境界反応は 0 本。
  → 「Ex_S が細胞質の代謝物から直接引き抜いている」という前提は正しくない。c0↔e0 の輸送反応を**新たに足すと、既存の輸送と二重になる**。そのため輸送反応は追加していない。
- 既存 23 本の変換は `scripts/analysis/screen_propionibacterium_helper.py::prepare_helper_model` が行ったもの。手順は「代謝物 id を共有プール id に変える → 区画を `e` にする → 反応 id を `EX_<pool>` に変える」で、反応は追加していない。今回も同じ規約をそのまま使った（区画は `e0` でなく既存の `e`）。
- 修正前、残り 173 本の分類は demand 169 本（うち 1 本は `Ex_S_biomass_ext`）と sink 4 本（H2S, Hg, Cd, Pb、下限 -1000）だった。

## 3. rxnnew73/74/75/78 — 変更しなかった

元論文の `P_sherm_model.xml` とリポジトリ版で、化学量論・上下限とも完全に同じ。つまり不均衡は**元モデル由来**である。値は cobra `check_mass_balance`（生成物 − 基質）。

| rxnnew74 RNA | -1.010 | -16.658 | -11.460 | -12.886 | -2.876 | -0.316 | 0 | +3 |

- 73–75 の不均衡は **R だけでは説明できない**（C・N などにも大きな差がある）。生成物の高分子（Protein `C4H5N2O3R2`、RNA `C15H23O19P3R3`、DNA `C15H23O13P2R3`）が ModelSEED の繰り返し単位の仮の式になっていて、消費する単量体の組成と対応していないのが原因。rxnnew73 は ATP の加水分解に使う水も書かれていない。

**炭素収支への影響（実測）:** 炭素の残差（取り込み C − 排出 C − 式ベースの biomass C）は、内部の不均衡反応による C の消失と数値的に一致した。消失の最大寄与は rxnnew73、次いで rxnnew66/63/74。

## 5. グリセロール — 反応は追加しなかった

- 経路は揃っている: 拡散 `rxn05581_c0`（CDS.1464）、glycerol kinase `rxn00615_c0`（CDS.1463）、嫌気型 G3P 脱水素酵素（menaquinone）`rxn08557_c0`（CDS.1320–1322）、フマル酸還元酵素 `rxnnew11_c0`（CDS.1432–1434）。**「glycerol kinase や G3P DH が欠けている」わけではない。**
- `EX_glyc_e` は元モデルが排出専用だったので、変換後も排出専用のまま。atlas や dFBA では培地にグリセロールがあっても取り込めない。
- テストのためだけに取り込み上限を開いた場合（参照培地 + glyc 10）:
  - μ = 0。
  - 増殖を要求しなければ、グリセロールは 19.80 まで取り込まれてプロピオン酸に変わる。
  - μ が回復した条件: O2 を与える（1.0228）、フマル酸を取り込ませる（1.0228）、MKH2→MK を自由に再酸化させる（1.0228）、乳酸 0.5 を加える（0.0421）。
  - 回復しなかった条件: NADH 酸化、NADPH 酸化、ATP 供給をそれぞれ自由にしても μ = 0。
- 診断: 余った還元当量が menaquinol（MKH2）に閉じ込められる。
  - モデルでグリセロールを酸化できるのは MK 依存の G3P 脱水素酵素 `rxn08557` だけ。グリセロールは 1 炭素あたりの還元度がプロピオン酸と同じなので、菌体を作った分の余剰電子は MKH2 として残る。
  - 嫌気条件で MKH2 を受け取れるのはフマル酸還元酵素と DMSO/TMAO/N2O 還元酵素だけで、後者の受容体は培地にない。
  - NAD(P)H で動く捨て先は存在する。propanal→propanol の `rxn01710`（CDS.932）と、硫酸→H2S である。しかし MKH2 から NAD(P)H へ戻す経路がない。
  - `rxnHYPOTHETICAL2_c0` は元モデルで (0,0)。テストで開いても還元型フェレドキシンが必要なため μ = 0 のままだった。
- テストのためだけに仮の NAD 依存 glycerol dehydrogenase（glycerol + NAD ⇌ DHA + NADH。DHA kinase `rxn00744`/`rxn00745` は既にある）を足した場合:
  - μ = 0.663。排出はプロピオン酸 5.54、propanol 4.80（`cpd03559`。式が `0.0` で壊れている）、酢酸 1.78、H2S 0.475。
  - propanol の排出を禁止すると μ = 0.616。
  - **この反応はモデルに入れていない。**
- 遺伝子の証拠
  - 補足資料 S4（汎ゲノム表）には「Glycerol dehydrogenase (EC 1.1.1.6)」の行がある。しかしモデルには対応する反応も遺伝子の紐付けもない。
  - S11（トランスクリプトーム）の CDS 番号はモデルの遺伝子 id と一致しない（例: glycerol kinase は S11 で CDS.3301、モデルで CDS.1463）。配列で対応付けない限り、モデル遺伝子の根拠としては使えない。
  - そのため、指示どおり追加しなかった。
- 推奨
  - CIRM-BIA1 のゲノムで gldA（EC 1.1.1.6）を配列レベルで確認する。確認できれば、GPR 付きで glycerol dehydrogenase を加えることを検討する。
  - あわせて propanol（`cpd03559`）の式を C3H8O に直すことも検討する。
  - グリセロールの取り込みを開けるかどうかは、表現型データで判断する。

## 6. 採用した場合のリスク（既存の dFBA 結果に対して）

- 既存の結果は変わらない（opt-in のため）。採用すると以下が変わる。
  - Pf が出す formate/succinate/CO2/pyruvate などがプールに入り、OR16/NS21 が利用できるようになる。そのため**動態の結果は変わりうる**。
  - CO2 の収支も変わりうる。
  - 反応 id が `Ex_S_*` から `EX_*` に変わる。
  - atlas の `model_fingerprint`、凍結した協調サロゲートの契約、学習済みの `*pfreud*` 辞書は、再構築または検証をやり直す必要がある。
- 未確認の点: 既存の `dfba_simulator` は `model.exchanges` の下限しか調整しない。そのため旧 sink（H2S/Hg/Cd/Pb、下限 -1000）は培地の制御の外で開いていた可能性がある。既存の結果でこの流束が実際に使われたかどうかは確認していない。
- Pf 専用のプールが 74 個（`cpd*_e`）プールの名前空間に増える。いずれも排出専用。
- `glcn__D_e` と `glcn_e` の食い違い（OR16/NS21）は未解決のまま残っている。
