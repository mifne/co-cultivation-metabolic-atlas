# 生理モデルの追加監査と長時間検証

2026-09-08。教師の大量収集を始める前に、新生理経路の実装を再点検し、PHA蓄積期を含む長時間検証を行う。

## 計算前に確認した問題と修正

|問題|影響|修正・検証|
|---|---|---|
|RLが生理モデルの版名を認識しない|旧方式のstep当たり供給、mmol基準PHA報酬、step当たりペナルティを選ぶ|生理モデルをaudited_rates_v2へ接続。実Env操作で同じ物理時間を1回/2回に分け、投入量・報酬・動態の一致を検査。旧制御契約の明示指定も拒否。|
|元の貯蔵交換が逆向きの場合、再利用無効でも供給可能|所有していないPHAを炭素・エネルギー源にできる|再利用無効なら取込下限を0に固定。有効時は自菌の現在の貯蔵量だけを上限とする。逆向き境界を持つGEMで無炭素条件を検査。|
|ATPMの分子式・電荷が欠落しても「残差なし」になり得る|不明な化学量論を検証済みとして受け入れる|分子式と有限の電荷を必須にし、欠落時は拒否。実際の3菌のATP加水分解反応は既知入力を使う。|

## 長時間の計算設計（結果を見る前に固定）

制御記録間隔0.25 h、kLa 10 h⁻¹、初期ゴム10 g/L、乳酸供給0.25 mmol/L/h、pH 7。
標準の3種接種量はOR16/NS21/Pf=0.5/0.1/0.03 g/L、2種は0.525/0.105 g/L。
維持ATPは0.1 mmol/g/h、基礎死滅率0.01 h⁻¹、最大飢餓死滅率0.1 h⁻¹。これらは未校正の検証用仮定である。

- 標準背景培地の2種・3種を24 h、内部刻み0.025/0.0125 hで対応比較する。
- 3種の0.05 h刻みも追加し、粗い刻みの影響を確認する。
- 3種で維持ATPを1にした条件、基礎死滅率0.02・最大飢餓死滅率0.2の条件を24 h計算する。
- 乳酸供給を12 hで止める条件、最初の4 hにNH4を0.1 mmol/L/h追加する条件を24 h計算する。ゴム等が残るので供給停止を完全な飢餓と同一視しない。
- PHA蓄積と貯蔵上限の検査用に、初期の既知N成分と未分類非ゼロ成分を除いた3種を12 h、0.025/0.0125 h刻みで比較する。これは仮想的な洗浄菌体条件であり、培養に適した最小培地や実測表現型を保証しない。除いた成分を全件記録する。

合計11ケース。値を大きくする条件だけを採用しない。失敗・途中軌道も保存する。

## 判定基準

PHA蓄積期を観測したとする計算上の閾値は生菌中PHA >0.001 g/L。実験的検出限界や有意差ではない。
対応する刻み間で、終点とピークのPHA差2%以内（分母の下限0.001 g/L）、菌種別生菌体差2%以内、3HVモル分率の絶対差0.001以内を初期の数値確認基準とする。基準を満たさない場合、教師収集に十分と判定せず原因と追加の刻み確認を記録する。

全時点の有限・非負、LP残差 <=1e-7、酸素連立残差 <=1e-6 mmol/L、酸素収支誤差 <=1e-8 mmol/L、貯蔵上限超過 <=1e-7 g/L、既知C/N台帳残差 <1e-6 mmol/Lを検査する。物理投入量と終了時刻も照合する。

生菌中PHA、死菌中PHA、両者の合計を別々に記録する。死菌中PHAは現在のRL報酬に含めていないため、総抽出量の最適化が完成したと説明しない。

結果・進捗は `results/physiology_long_validation_20260908/`。`design.json` と `sources/` が実行ソース・GEM・ゲノムを固定する。実行中の対象ソースは変更しない。
