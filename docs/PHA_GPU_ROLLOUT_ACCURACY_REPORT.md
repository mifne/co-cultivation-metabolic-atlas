# PHA terminal accuracy improvement for GPU-only cooperative dFBA

## Outcome

The qualified GPU artifact is
`models/cooperative_surrogate/cooperative_neural_reranker_34448_dagger2_rebased.pt`.
On the predefined five 120-step equal-action trajectories, terminal PHA relative
error decreased from 1.237% mean / 1.711% maximum to 0.627% mean / 0.861%
maximum. All 600 GPU requests were feasible and no online CPU LP was called.

## Diagnosis

The previous path usually ended the QP projection at zero iterations because the
first reranked exact-flux anchor already satisfied the live bounds. Profiling
therefore separated the runtime into approximately 0.15 s per-step solver time,
of which about 0.11 s was context construction, dictionary search and candidate
materialisation; the accumulated QP time was only about 1 s per 120-step run.
The PHA discrepancy was consequently not a QP convergence failure. It was a
single-anchor quantisation and rollout-distribution problem: a one-step model
trained on CPU-generated states was queried on states generated by its own prior
GPU predictions.

## Implemented correction

1. GPU rollout contexts are now capturable without changing the accepted flux.
2. `augment_cooperative_surrogate_dagger.py` runs independent GPU-only
   trajectories and relabels each visited state with the exact three-stage CPU
   HiGHS solution at identical bounds, biomass and shared-medium supply.
3. Two DAgger iterations added 720 focused anchors: 33,728 -> 34,448 candidates.
4. The existing better-generalising neural weights were retained and rebased to
   the new exact dictionary. A naive retraining experiment was rejected because
   its PHA flux RMSE worsened from 0.00135 to 0.00312.
5. Candidate-pool, decision-strength and convex-blend parameters are explicit
   runtime options. Unqualified large-pool and uniform-blend settings are not
   enabled by default.

## Rejected alternatives

- Rerank pool 512 with only 128 projected candidates caused eight infeasible
  steps in one trajectory.
- Uniform eight-anchor convex blending preserved linear feasibility but mixed
  low-growth alternative optima and caused large rollout errors in some seeds.
- A 2,048-candidate pool allowed neural prediction error to select
  context-distant anchors and increased the worst-seed error.
- Direct neural PHA-target interpolation strongly underestimated terminal PHA.

These failures illustrate that FBA feasibility and agreement with a particular
lexicographic CPU optimum are different requirements.

## Final validation

| Metric | Before | DAgger-2 |
|---|---:|---:|
| PHA relative error, mean | 1.237% | 0.627% |
| PHA relative error, maximum | 1.711% | 0.861% |
| Mean speed-up | 2.67x | 2.81x |
| Maximum biomass absolute error | 0.001161 g/L | 0.000541 g/L |
| GPU feasible requests | 600/600 | 600/600 |
| Online CPU LP calls | 0 | 0 |
| Peak allocated VRAM | 900 MiB | 918 MiB |

The performance comparison uses the original sequential CPU reference times;
parallel CPU reference generation was used only to shorten offline validation.

## Literature basis

- Faure et al. embed mechanistic metabolic constraints in a neural architecture:
  https://doi.org/10.1038/s41467-023-40380-0
- Ross et al. introduce DAgger, which labels states induced by the learned
  policy rather than only expert-distribution states:
  https://proceedings.mlr.press/v15/ross11a.html
- Bengio et al. describe exposure bias and accumulated sequence error:
  https://proceedings.neurips.cc/paper/2015/hash/e995f98d56967d946471af29d7bf99f1-Abstract.html
- List et al. show that unrolled training mitigates distribution shift and
  rollout error in neural scientific simulators:
  https://doi.org/10.1016/j.cma.2024.117441

The five validation seeds must remain held out from future DAgger collection.
External action distributions and longer rollouts remain necessary before a
biological conclusion is made.
