# 修正後21条件の3菌比較：解釈と公平性

対象：`scripts/analysis/reassess_audited_symbiosis_20260908.py`。本書は計算結果を見る前の解釈上の制約を記録する。コード・モデル・条件は変更していない。

## どの比較が何を意味するか

各条件内の主要比較は、初期総菌体0.63 g/L、OR16:NS21比5:1、培地、乳酸流入、kLa、pH、12時間の評価時間が揃う。この比較は「一定の総接種量で、一部をPfに置換する価値」を評価する。

| 構成 | OR16 g/L | NS21 g/L | Pf g/L | 用途・限界 |
|---|---:|---:|---:|---|
| three | 0.500 | 0.100 | 0.030 | 評価対象。固定した接種比の結果 |
| two_equal_total | 0.525 | 0.105 | 0 | 総菌体を揃えた主要対照 |
| two_fixed | 0.500 | 0.100 | 0 | OR16/NS21の初期量を揃えた追加対照。総菌体は0.60 |
| inert_pf | 0.500 | 0.100 | 0.030 | Pfの全反応を0にした低酸素条件の数値対照。死菌・熱殺菌・吸着作用の実験モデルではない |
| ns21_alone | 0 | 0.630 | 0 | 同じ総接種量での単菌対照。三菌中のNS21初期量とは異なる |
| pf_alone | 0 | 0 | 0.030 | 三菌中と同量のPf。総接種量を揃えた生産順位には使えない |
| ns21_pf | 0 | 0.484615 | 0.145385 | 総菌体0.63の二菌対照。三菌とはNS21/Pfの絶対量も大きく異なる |

two_fixedは基準・低酸素で実施し、inert_pfは低酸素のみ。三菌とinert_pfの差は、この数理モデルでPfの代謝を動かす効果を評価する。Pf添加による競争、増殖による密度効果、代謝物の受け渡しを含む総効果であり、その全差をプロピオン酸の受け渡しに帰属させない。

NS21単菌が良好なら、三菌がOR16+NS21二菌を上回っても「三菌が必要」とは言えない。OR16+Pfを含む全二菌構成、全接種比を網羅した設計ではない。現在の生産目的はNS21のPHA経路に置かれていることも明記する。

## 生産量・効率・供給時刻を区別する

- 主要な陽性判定は、**同条件の総接種量を揃えた二菌に対しPHAが5%超増加し、ゴム除去の低下が5%以内**という探索用基準。測定誤差から導いた有意差ではない。
- 乳酸高供給は1.0 mmol/L/h、基準は0.25 mmol/L/hで、12時間の投入乳酸は12対3 mmol/L。条件をまたいでPHA量を比べる場合、追加炭素量が異なるためそのまま高効率と呼ばない。
- nitrogen_stagedは最初の4時間にNH4を0.1 mmol/L/h追加し、基準より総NH4投入が0.4 mmol/L多い。同条件内の二菌対三菌は公平だが、基準との差から「窒素をこの時刻に供給する利点」を単独には推定できない。時刻の価値には等量の定速供給・一括供給との追加比較が必要。
- kLa=10/50 h⁻¹は操作条件の仮定。実機のガス量・消費電力・撹拌条件への較正がないため、kLa差をそのまま電力削減額へ変換しない。

## 背景培地、B12、安定性

初期glucoseとYEを0にしても、`get_initial_params`由来のアミノ酸、核酸関連物質、ビタミン等が残る。これらは炭素・窒素を供給し得る。したがって「外部乳酸0」は「ゴムのみが炭素源」と同義ではなく、NH4の消失・再分泌は全窒素の枯渇・生産と同義ではない。ゴム由来PHA割合の主張には、全基質の元素会計または標識実験等が必要。

Pfは酸素摂取を閉じた代謝型であり、同一槽の酸素環境に対する実際の生理応答が検証されたわけではない。OR16/NS21には共有B12供給を増殖必須性につなぐ受け取り系が表現されない。B12の分泌0でも、実生物におけるB12の価値がないとは言えない。逆にモデル上分泌可能でも共生の根拠とはならない。

維持代謝要求、飢餓死滅、PHA再利用、実測の種別阻害特性を較正していない。12時間後に三菌が残ることや菌体量が増えることは、長期の安定共存、相利共生、供給停止への耐性、連続培養での非流失を証明しない。Pf単独との初期Pf量を揃えた比較は参考になるが、NS21単独・NS21+Pfでは初期NS21/Pf量が異なるため、菌ごとの利益の直接判定は限定される。

交換量最小化は、多数のLP最適解から選ぶ明示的な数値規則である。交換の総積分は受け渡し候補を示すが、炭素の出所や特定菌由来を追跡する標識データではない。LPの二次目的を変えても残る機構かどうかの確認が必要。

## 数値確認と結論の範囲

21条件は決定論的な条件走査であり、独立実験21反復ではない。p値や統計的有意差を付けない。

基準と低酸素には0.025→0.0125 hの二菌・三菌の対応比較が含まれる。no_lactate、lactate_rich、nitrogen_stagedに陽性候補が出た場合も、陽性と確定して報告する前にその条件の両構成を細刻みで追加確認する。細刻みで符号が変わる差、数値差と同程度の小さな優位は保留する。失敗した条件や陰性条件を除外しない。

報告では、(1)計算の収支が改善したこと、(2)固定した条件での生産優位、(3)代謝物交換の候補、(4)実験での三菌共生の根拠を分ける。数値実装の修正によって、未較正の生物学的課題まで解決したとは表現しない。
