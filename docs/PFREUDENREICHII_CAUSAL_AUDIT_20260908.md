# 1時間刻みの陽性原因と安定優位の再評価

詳細・全条件表：[因果診断レポート](../results/pfreud_causal_20260908/REPORT_JA.md)

- 1時間刻みのPHA +20.19%は、NH4閾値による生産モードの切替スケジュールが主因。2×2の対称反実仮想分解では差の90.40%がスケジュール成分。
- 3分刻み・連続乳酸供給の陽性はPfのプロピオン酸を系外除去すると消失する。交差供給が動態に影響することは確認。
- 45秒刻みでは3種0.482322 g/L、総接種量を合わせた2種0.496733 g/L。大きな3種優位は頑健ではない。
- 22.5秒刻みまで完了。3種0.458632 g/L、生産菌接種量一致の2種0.470977 g/L、総接種量一致の2種0.485581 g/L（3種はそれぞれ−2.62%、−5.55%）。PHA終点量だけで酸素動態の収束を認定しない。
- 酸素をステップ冒頭だけで移動させる分割更新にも大きな刻み依存がある。操作間隔と内部積分刻みを分離し、酸素移動・消費と閾値イベントの整合性を改善してから制御性能を判定する。
- 本結果は実測・統計的有意差・長期生産安定性の証明ではない。最新の細刻み比較は詳細レポートとresolution_and_feed.csvを参照。

収集プロセスの別件の停止：[240軌道後のLP証明検査失敗](../results/pfreud_causal_20260908/COLLECTION_STATUS_NOTE_JA.md)。現行GEM・本番シミュレータを本診断のために変更していない。
