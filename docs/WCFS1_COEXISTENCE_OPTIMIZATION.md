# WCFS1 2022 GEMの修復と三種共存条件の再計算

## 結論

乳酸菌の本番GEMを、2006年版iBT721から2022年版WCFS1ネットワーク（BioModels `MODEL2210190005`）へ更新した。ただし、公開2022モデルは全交換反応を開いてもバイオマスフラックスが0であり、そのままでは使用できなかった。監査により、バイオマス式が切断されたL-Lys/D-Ala型ペプチドグリカンを要求する一方、WCFS1で実証されているmDAP/D-Lactate型経路の `UGMDDS2` が欠落していることを特定した。

修正版は、2022年版の1208反応・915 GeneProductからなるネットワークを基盤とし、iBT721で実験的に拘束されたWCFS1バイオマス式と `UGMDDS2`（GPR: `lp_0518`）を復元した。交換反応、sink、demand、栄養バイパスは追加していない。Gene ID正規化では`GntK`を同一遺伝子`lp_1250`へ統合し、論理的に冗長な`lp1406`をGPRから除外したため、修復後は1209反応・976代謝物・913 GeneProductとなった。全交換開放診断では正のバイオマスフラックスを回復している。

## 修復前モデルの問題

| 項目 | 2022公開モデル | 修正版 |
|---|---:|---:|
| BioModels | MODEL2210190005 | MODEL2210190005を基盤に修復 |
| 反応 | 1208 | 1209 |
| 代謝物 | 976 | 976 |
| GPR付きGeneProduct | 915 | 913（同一別名統合・冗長ID除外後） |
| WCFS1 `lp_*` locus tag | 912 | 912 |
| 全交換開放時の増殖 | 0 | 正 |
| バイオマス細胞壁成分 | 切断された `peptido_LPL_c` | `PGlac2_c`（mDAP/D-Lac型） |
| `UGMDDS2` | 欠落 | `lp_0518`を伴って復元 |

2022公開モデル内には、`PAPPT5`、`UAGPT5`、`PGGT4`を含むmDAP/D-Lactate型細胞壁経路が存在する。しかし、D-Ala-D-LacをUDP-MurNAc-mDAP前駆体へ結合する次の反応だけが欠落していた。

`alalac_c + ATP + ugmd_c -> ADP + H+ + Pi + ugmdalac_c`

さらに、公開2022モデルのバイオマス式には、iBT721式に対してCPS係数 `0.1294 -> 1.4`、NAD係数 `0.002 -> 0.0002` という転記差があった。修正版では、WCFS1培養データに基づくiBT721の `biomass_LPL60` を、2022モデル内の対応代謝物へ一対一で移植した。

修復は [repair_wcfs1_2022.py](/home/reiya/co-cultivation/scripts/model_ops/repair_wcfs1_2022.py) で再現でき、入力・出力ハッシュと全変更点は [repair provenance](/home/reiya/co-cultivation/models/sbml/reference/Lplantarum_WCFS1_Koduru2022_repair.json) に保存している。

## 修正した計算構造

1. 各GEMの `S_i v_i = 0` をブロック行列として保持する。
2. 細胞外代謝物IDを共通化し、三種を同じ培地プールへ接続する。
3. 各外部代謝物について `sum_i X_i a_ij v_ij <= C_j/dt` を課し、総消費量を培地在庫と同時分泌量以下に制限する。
4. 第1段階で `max min_i mu_i` を解き、維持設計の共通増殖上限を0.005 h^-1とする。
5. 共通増殖の99%を固定し、環境交換フラックスのL1ノルムを最小化する。
6. 同一時間区間内の分泌と取り込みを共有プールで相殺するが、消費量が外部供給と分泌の合計を超える解は禁止する。

## 修正版2022モデル用の定義共通培地

従来の9成分供給に、2022モデルで顕在化したpyridoxamine要求を追加した。ValとMetは三種共有LP内の分泌で補われるため、定義供給液には追加しなかった。

|---|---:|---:|---:|
| D-Glucose | 0.5000 | 2.1619 | 45.040 |
| L-Arginine | 0.0500 | 0.2090 | 4.355 |
| L-Tryptophan | 0.0500 | 0.2451 | 5.106 |
| L-Leucine | 0.0500 | 0.1574 | 3.279 |
| L-Glutamate | 0.0500 | 0.1766 | 3.678 |

## 24時間dFBA比較

条件は初期菌体量OR16 0.5、NS21 0.1、WCFS1 0.1 g L^-1、pH-stat 6.5、KLa操作値100、時間刻み0.5 hである。

| 条件 | 成分数 | 24 h供給質量 (g L^-1) | OR16終点/初期 | NS21終点/初期 | LP終点/初期 | LP正増殖 | 能動的共存 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 無給餌＋協調LP | 0 | 0 | 1.000 | 1.000 | 1.000 | 0/48 | 不成立 |
| 定義10成分＋独立FBA | 10 | 3.155 | 1.761 | 2.208 | 1.000 | 0/48 | 不成立 |
| **定義10成分＋協調LP** | **10** | **3.155** | **1.121** | **1.121** | **1.121** | **48/48** | **成立** |
| 完全16成分×4＋独立FBA | 16 | 14.329 | 3.594 | 3.273 | 7.491 | 48/48 | 成立（過剰・不均衡） |

定義10成分＋協調LPは、完全16成分×4条件に比べて供給質量を78.0%、成分数を37.5%削減しながら、三種の終点/初期比を約1.121へ揃えた。独立FBAでは同じ10成分を供給しても乳酸菌の正増殖が選択されないため、栄養供給だけでなく共有培地を結合した協調目的が必要である。

24時間に予測された主な総分泌量は、Val 1.270、Cys 0.000975、Met 0.0000356 mmol L^-1であった。これは培地への総分泌予測であり、特定の生産者から消費者へ実際に移送された実測量ではない。

## 実験前に必要な検証

- 使用予定株がWCFS1でない場合は、その株のゲノムからGEMを再構築して全計算をやり直す。
- 10成分を1成分ずつ除くdropout試験を、単独培養と三種培養の双方で行う。
- Val、Met、Cysおよびpyridoxamine/pyridoxal-5-phosphateをLC-MS/HPLCで追跡する。
- 無給餌条件は菌体量が一定でも増殖フラックス0であり、共存成功とは扱わない。
- 協調目的は系全体が協力する上限設計であり、各菌が自然に同じ分泌表現型を選択する保証ではない。
- 2022モデルには式が `R` または `X` のポリマー代謝物が残るため、該当反応の完全な元素収支検証はできない。
- 旧iNF517/iBT721で学習したGPUサロゲートは反応順序と化学量論が一致しないため再利用せず、修正版2022モデルで再学習する。
