# 2種・3種の同一資源予算下での供給探索

結果を見る前に固定した設計。対象は修正後のPhysiologyDFBASimulator。

24時間、背景培地は同一辞書、ゴム10 g/L、初期総生菌体0.63 g/L、外部乳酸6 mmol/L、追加NH4 0.4 mmol/L。3種の接種量はOR16/NS21/Pf=0.5/0.1/0.03、2種は0.525/0.105 g/L。接種比は今回探索しない。

乳酸は24時間均等、前半12時間集中、後半12時間集中の3通り。NH4は最初の4時間、最初の12時間均等の2通り。全6供給候補を両構成で漏れなく評価する。上限供給速度は乳酸0.5、NH4 0.1 mmol/L/hで共通。

kLa=2/10/50 h^-1を別々の資源条件として比較し、酸素能力が違う行の最良値を競わせない。各行では同じkLa、酸素飽和濃度、24時間の供給能力を与える。実酸素移動・消費は需要に依存するため同量に強制せず別途保存し、移動量がkLa×飽和濃度×時間を超えないことを検査する。初期DOも同じ。曝気能力の同等性であり、酸素実消費量や電力費の同等性ではない。

維持代謝0.1 mmol ATP/g/h、基礎死滅0.01 h^-1、最大飢餓死滅0.1 h^-1、capacity_ratio、PHA再利用有効、pH 7を共通仮定とする。pH制御の酸・塩基の費用は最適化対象外。

主指標は24時間後の生菌中PHA g/L。死菌PHAを含む総量、ゴム除去、3HV組成、実酸素消費を副指標として記録する。副指標へ後から主指標を置き換えない。

第1段階は内部刻み0.025 hで36ケース。各酸素条件・構成で主指標上位2候補と最良値から4%以内の候補を抽出する。その和集合を2種・3種の双方で0.0125 hに細分して再評価する（同じ細分評価数、最大36ケース）。両構成の候補を相互に適用するため、片方にだけ都合のよい条件で比較しない。

細分後の候補内最良値で比較し、終点PHAと菌種別終点菌体の刻み差2%以内を確認する。PHAの分母下限0.001 g/L、菌体の下限1e-6 g/L。3種が5%超増産し、ゴム除去の低下5%以内であれば工学的候補とする。統計的有意差や必然性とは呼ばない。数値基準未達なら追加細分が必要とする。

これは有限6候補・固定接種比の探索で、全球最適化でもRL学習でもない。未校正のB12依存、Pf酸素表現型、維持・死滅、PHVゲート、ゴム由来炭素の特定は別課題。菌体接種に含まれる元素組成の違いまで同じと仮定しない。
