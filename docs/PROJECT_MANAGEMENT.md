# プロジェクト管理・ロードマップ (PROJECT_MANAGEMENT.md)

本プロジェクトの変遷史、戦略的決定、および今後の展望を管理します。

## 1. プロジェクトの変遷 (Project Evolution)

本プロジェクトは、当初の設計からいくつかの重要な技術的転換を経て、現在の「精鋭 3 種体制」へと進化しました。

- **Phase A: 初期 4 種体制**:
    - 構成: OR16, NS21, P. putida, S. japonicum.
    - 課題: モデル間の競合と、一部モデルの低品質（Ghost Growth）が判明。
- **Phase B: 3 種への精鋭化**:
    - 決定: *S. japonicum* を排除し、信頼性の高い *L. plantarum* (iNF517) をバッファーとして導入。
    - 理由: 代謝特性の明確化と、RL制御の安定化のため。
- **Phase C: 物理的厳密性の追求**:
    - 改善: シミュレータの炭素収支を 0.1% 以下の精度に向上。
    - 成果: 質量保存則に基づく、真に科学的なシミュレーション環境の構築。

## 2. コンソーシアム選定の根拠

| 微生物名 | 役割 | 選定理由 |
| :--- | :--- | :--- |
| **OR16** | The Engine | 強力な Lcp 酵素系による高分子ゴムの初期分解能。 |
| **NS21** | The Converter | Rox 酵素系による中間体資化と、高い PHA 蓄積能力の共存。 |
| **L. plantarum** | The Buffer | 複雑なコンソーシアムにおけるアミノ酸・ビタミンの安定供給。 |
