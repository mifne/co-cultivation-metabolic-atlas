# 強化学習を用いた三種共培養・流加制御系の到達指標

## 最終目標

Actinoplanes sp. OR16、Rhizobacter gummiphilus NS21、Lactiplantibacillus plantarum WCFS1の三種を維持しながら、ゴム由来炭素をPHAへ変換する1 L流加培養を、測定可能な状態量から再現可能に制御する。強化学習（RL）の役割は、固定流加より少ない資源で、共存、ゴム分解、PHA蓄積を同時に維持・改善する操作系列を提案することである。

モデル内の達成は実培養の達成を意味しない。以下のStage 0–2は計算上の到達、Stage 3–5は湿式実験を含む到達とする。

## Stage 0: モデルと計算の健全性

| 指標 | 到達基準 |
|---|---|
| 使用モデル | OR16、NS21、WCFS1 2022修復モデルの3種のみ |
| Gene ID | gene registryのcanonical ID検査に合格 |
| FBA解 | 評価中の解成功率99.5%以上、非有限値0件 |
| 物質収支 | ゴム切断層のC5等価炭素誤差が許容誤差内 |
| 再現性 | モデルSHA-256、seed、コード、条件、全生データを保存 |

## Stage 1: RL問題設定の到達可能性

| 指標 | 到達基準 |
|---|---|
| 三種維持 | 24 h後の各菌体量が初期値の90%以上、絶対量0.01 g L⁻¹以上 |
| pH | pH-stat設定6.5に対して6.3–6.7 |
| ゴム分解 | 少なくとも無操作対照を上回る正の分解量 |
| PHA | NS21由来PHAが正で、計算中に非減少 |
| 操作可能性 | 流加倍率とkLa操作が観測・報酬へ反映される |
| 流加液 | Defined-10は計算用基準液、Glu+Ile+pyridoxamineは湿式未検証候補として区別 |

## Stage 2: RL効果の計算実証

主要対照は25%固定操作 `action=[0.25,0.25,0.25,0.25,0.25]` とする。無操作対照、低流加・最大酸素移動、二段階ルール制御も併記する。24 h効果確認では、Defined-10の有効域（約0.004–0.008倍）をPPOが解像できるよう、共通流加行動0–1を実倍率0–0.02へ写像する。従来の0–2写像では有効域が行動空間下端0.4%未満に圧縮されるため、これは報酬調整ではなく数値条件の修正である。

学習効果ありの事前判定は、未学習とは独立した5つの初期条件摂動シナリオで次をすべて満たすこととする。

1. Stage 0、Stage 1の制約を全シナリオで満たす。
2. RLと25%固定操作のペア差について、エピソード非正規化報酬の95%信頼区間下限が0を超える。
3. 平均PHA量と平均ゴム分解量が25%固定操作以上である。
4. 平均Defined-10添加質量が25%固定操作以下である。
5. 学習チェックポイント、VecNormalize統計、行動時系列、評価生データを保存する。

低流加・最大酸素移動ルールは強い機構ベース対照であり、これに対する優越は必須停止条件ではない。RLがこの対照を下回る場合は、RL導入の利点を主張せず「固定25%より改善したが、単純ルールを超えていない」と結論する。

## Stage 3: 小容量培養でのモデル候補検証

| 指標 | 到達基準 |
|---|---|
| 三種絶対量 | 種特異的qPCR/ddPCRで24 h後に全種維持 |
| 流加液 | 0.5×、1×、2×、5×および-Ile、-pyridoxamine、-Gluを比較 |
| 代謝物 | Glu、Ile、B6 vitamers、有機酸の時系列収支を取得 |
| ゴム・PHA | ゴム重量/FTIR/SEC-GPCとPHA GCを菌体量から独立して測定 |
| 反復 | 最低3生物学的反復。モデル反復を生物学的nとしない |

## Stage 4: 1 Lジャーファーメンターでの閉ループ実証

- pH、DO、温度、撹拌、流加実重量、酸・塩基添加量を同期記録する。
- 手動採取時刻と採取体積を物質収支へ反映する。
- 固定流加、ルール制御、RL提案制御を同じ初期条件で比較する。
- RLが利用できる観測は実機で測定可能な量に限定する。
- 主要評価項目は三種維持、ゴム分解量、PHA g L⁻¹、PHA %DCW、流加質量とする。

## Stage 5: 制御系としての確立

独立培養日に再現し、センサー欠測、ポンプ誤差、初期菌比変動に対するロバスト性を確認する。最終的には、固定・ルール制御に対する効果量と95%信頼区間、安全制約違反率、1 g PHA当たりの流加原料量・運転時間を報告する。

## 現時点の位置

- Stage 0: コードテストとモデル識別は合格。
- Stage 1: WCFS1修復後モデルで三種共存と流加候補を計算確認済み。
- Stage 2: 本書の基準で新規PPO学習を実施し、旧モデル由来学習結果は使用しない。
- Stage 3以降: 未達。湿式実験が必要。
