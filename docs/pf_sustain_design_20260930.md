## 推奨する最小条件と代償
- kLa 10（PHA の主条件）を保つ場合の最小条件: lactate 0.5 mM/h を 24 h まで続け、NH4 0.05 mM/h を 24 h 供給する（r2_AB_k10）。
  - Pf は 1.008 倍。ほぼ維持だが増殖ではなく、24 h 時点の μ は −0.003/h でゆっくり低下している。
  - OR16 / NS21 / PHA は baseline よりむしろ増えた（.509 / .201 / .802、baseline は .449 / .195 / .698）。
  - 代償は投入量で、lactate が 6 → 12 mM、NH4 が 0.4 → 1.2 mM になり、等予算の比較からは外れる。
  - NH4 を 0.1 mM/h（2.4 mM）にすると PHA は 0.266 に落ちる（−62%）。N の上げすぎは逆効果である。
- 明確な純増殖が得られた条件: kLa 2 + lactate 0.5×24 h で 1.35 倍、kLa 2 + 1.0×24 h で 1.88 倍。
  - PHA は 0.118 / 0.590 で、k10 baseline の 0.698 を下回った。ただし k2 baseline の 0.023 は上回った。
  - k10 では、lactate を倍の 1.0×24 h にしても 1.06 倍にとどまった。
- 結論: 維持には lactate の 24 h 継続が必要条件で、k10 では NH4 の継続も必要。増殖は kLa 2 でのみ得られた。k10・Pf0 0.03 では、どの供給レバーでも Pf の lactate 取り分は 2–4% にとどまった（Pf0 0.15 で 9–17% に上がるが、倍率は下がる）。
- コード・モデル変更が必要なレバー（未実施）: lactate は OR16 / NS21 も取り込め、在庫は生菌量比例の等比率で分けられ余りは再配分されないので、「Pf 専用の供給」はモデル上成立していない。Pf に優先させるには、種別 Km / Vmax の親和性競合を compute_uptake_limits に入れるか、OR16 / NS21 の lactate 取り込み下限を根拠に基づき制限する必要がある。

## 検証していないこと
- 24 h より長い培養（r2_AB_k10 は μ<0 なので長くすると低下する可能性が高い）。refine の dt 0.0125 h、two arm、legacy / audited、RL・surrogate の経路（RL の audited_rates_v2 は lactate ポンプ上限が既定 0.1 mM/h〔--max-specific-feed-rate〕で、本稿の 0.5–1.0 mM/h を超える）。
- kLa や NH4 速度の中間値、Pf 初期量の他の値、交絡のない交互作用の推定、ウェットでの妥当性（lactate の残留、N の形態）、pH 制御のコスト
