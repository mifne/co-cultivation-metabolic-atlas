# 天然ゴム分解・PHA変換コンソーシアム 最終報告書 (2026-04-25)

## 1. プロジェクトの総括
本プロジェクトでは、動的フラックスバランス分析（dFBA）と強化学習（PPO）を統合し、天然ゴムを効率的に分解し PHA（ポリヒドロキシアルカン酸）へと変換する最適な微生物コンソーシアムの構築と制御戦略の獲得に成功した。

## 2. 最終コンソーシアム構成（精鋭 3 種）
1.  **Actinoplanes sp. OR16 (Engine 1: Lcp-type)**
    - エンド型分解によりゴム高分子をオリゴマーへと断片化する。
2.  **Rhizobacter gummiphilus NS21 (Engine 2: Rox-type & Converter)**
    - オリゴマーを特異的に資化し、自身の菌体内に PHA を高蓄積する。
3.  **Lactobacillus plantarum (Buffer/Stabilizer)**
    - ビタミン・アミノ酸を供給し、系全体の代謝ロバスト性を維持する。

## 3. 主要な達成指標
- **ゴム分解率**: 平均 **37.95%** (200時間運用時)
- **以前の 3 種系比**: 約 **1.44 倍** の分解効率向上
- **代謝シナジー**: Lcp (OR16) と Rox (NS21) の連携による、物理的な連鎖分解フローの確立を確認。
- **制御戦略**: RLエージェントによる、アミノ酸・グルコースの動的補給による 3 種共存状態の維持。

## 4. 技術的ハイライト
- **De novo 構築**: OR16 および NS21 のゲノム情報を起点とした高品質 GSMM の構築。
- **シナジー実装**: 「高分子 $\rightarrow$ オリゴマー $\rightarrow$ ODTD $\rightarrow$ PHA」という具体的な代謝バトンタッチを数理モデル化。
- **高速シミュレーション**: NN サロゲートモデルの導入により、複雑な 3 種系の学習を 100k ステップまで完遂。

## 5. 今後の展望
- **スケールアップ**: 実際のバイオリアクターにおける pH や溶存酸素の物理制約を加味したシミュレーション。
- **遺伝的改良**: シミュレーションで特定されたボトルネック（特定の酵素の反応速度）をターゲットにした遺伝子組換え案の策定。

---
**結論**: 数理モデルと AI の融合により、天然ゴムという難分解性資源の循環利用に向けた強力な基盤を確立した。
