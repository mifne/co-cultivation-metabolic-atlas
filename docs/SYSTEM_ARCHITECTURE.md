# システム・アーキテクチャ仕様書 (SYSTEM_ARCHITECTURE.md)

本プロジェクトの核心である「多段階代謝シナジー」および「dFBA-RL 統合制御」の技術的定義を記述します。

## 1. 代謝シナジーの物理的・生化学的定義

天然ゴム（高分子）から PHA（有用物質）への変換は、以下の 3 段階の物理的連鎖として実装されています。

### 🪜 変換プロセスと代謝プール
| 段階 | プロセス | 酵素系 (担当菌種) | 代謝物プール (ID) | 物理的状態 |
| :--- | :--- | :--- | :--- | :--- |
| **Stage 1** | エンド型ランダム切断 | Lcp (OR16) | `rubber_high` $\rightarrow$ `rubber_fragment` | 固体 $\rightarrow$ 水溶性オリゴマー |
| **Stage 2** | エキソ型精密切断 | Rox (NS21) | `rubber_fragment` $\rightarrow$ `odtd_e` | オリゴマー $\rightarrow$ 資化性中間体 (C15) |
| **Stage 3** | 代謝変換・蓄積 | Central Met. (NS21) | `odtd_e` $\rightarrow$ `Acetyl-CoA` $\rightarrow$ `PHA` | 細胞内ポリマー |

### 🔬 数学的根拠
OR16 が `rubber_high` を切断することで、環境中のオリゴマー末端濃度が増加します。NS21 の Rox 酵素はこの「末端」のみを認識して ODTD を切り出すため、OR16 の活動が NS21 の PHA 生産速度を直接的に律速解除（ブースト）する設計となっています。

## 2. dFBA-RL 制御アーキテクチャ

システムは、生物学的リアリティ（dFBA）と知的な意思決定（RL）を高度に融合させています。

### 🔄 統合ループ
1.  **Environment (dFBA Simulator)**:
    - 3 種の代謝モデルを同時に計算。
    - **動的境界条件制御**: 培地中の代謝物濃度（ゴム、グルコース等）に基づき、各ステップで FBA モデルの `lower_bound` を動的に更新（ミカエリス・メンテン型）。
    - **堅牢なフラックス追跡**: `EX_pha_c` や `EX_biosurfactant_e` などの交換反応を自動マッピングし、生産量を正確に追跡。
    - 質量保存の法則を 0.1% 以下の精度で厳密に遵守。
2.  **Agent (PPO Agent)**:
    - 状態（代謝物・バイオマス状況）を観測。
    - アクション（グルコース・アミノ酸の動的補給量）を決定。
3.  **Reward Function**:
    - 「PHA の生産最大化」と「系全体の持続可能性（3 種の生存）」を最適化指標とする。

## 3. 科学的妥当性の証明

- **質量収支**: すべての炭素原子は、`docs/FINAL_MASS_BALANCE_PROOF.png` に示される通り、シミュレーション全期間を通じて厳密に追跡されています。
- **シナジー効率**: 2 種の連携により、単独種では不可能な高分子ゴムからの PHA 蓄積率を達成しています。
- **ロバスト性**: *L. plantarum* による代謝バッファー効果により、栄養枯渇による系の崩壊を防いでいます。
