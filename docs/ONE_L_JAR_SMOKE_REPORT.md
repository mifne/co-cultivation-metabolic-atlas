# 1 L jar virtual smoke-test report

## 結論

1 Lジャーファーメンターを模した仮想条件において、4系統の送液、pH-stat、サンプリング、液量変化、撹拌・通気に依存する `kLa`、および3種GEMの逐次FBAを結合した6時間のsmoke-testは合格した。17回（独立16条件＋決定論的再実行1回）の全計算で局所判定と全体判定が成立し、全pytestも79件合格した。

この結果が示すのは、実験前の仮想計算を進めるためのソフトウェア経路が動作し、少なくとも今回の範囲では数値破綻がないことである。3種共存や流加戦略の生物学的妥当性を実証した結果ではない。

## 実行条件

- 時間幅: 6 h
- 時間刻み: 0.5 h
- 独立条件: 4制御方策 × 4仮想パラメータ条件 = 16条件
- 再現性確認: 代表条件の同一seed再実行1回
- FBA: HiGHS dual simplexによる厳密解
- 操作: 4ポンプ、pH調整用酸・塩基、サンプリング、撹拌速度、通気量
- 不確実性: 初期液量、ゴム量、3菌の初期バイオマス、培地濃度、ポンプ効率、`kLa`倍率、ポリマー分解倍率

再実行コマンド:

```bash
python3 scripts/run_one_l_jar_smoke.py
```

## 解釈と限界

3菌すべてが短時間に消失せず、制御入力に応じて液量、酸素移動、ゴム分解、PHAが有限値として応答したため、次の計算段階へ進む最低条件は満たした。ただし初期値と変動幅、`kLa`較正式、ポンプ原液濃度、ポリマー分解倍率は仮想値を含む。したがって現時点の数値を実験予測値や購入根拠の性能値として扱ってはならない。

また、今回厳密に確認した保存則は液量収支、各GEM内部の定常状態制約、非負状態である。系全体の炭素・窒素元素収支は、交換代謝物の化学式とポリマー擬似反応を監査した後に別途検証する必要がある。
