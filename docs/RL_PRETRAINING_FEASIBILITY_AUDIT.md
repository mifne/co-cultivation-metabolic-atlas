# 3種共存・強化学習問題設定の事前実行可能性監査

## 結論

現行の3種GEMは、**条件を整えれば3種共存とPHA生成を同時に実現できる**。したがって、
生物モデルそのものが完全に不可能な組合せではない。一方、現行のRL環境はpHを観測して
罰するだけで塩基滴定を操作できず、NS21の目的関数切替に使うNH4濃度も観測できない。
このため現状は **NOT_READY_STRUCTURALLY_UNDERCONTROLLED**、すなわち学習アルゴリズムの
性能以前に操作・観測設計が不足している。

PPOを長時間学習させる前に、pH-stat操作、NH4観測、二段階給餌、1種脱落制約を追加し、
無学習の決定論的対照で168時間の成立性を確認する必要がある。

## 共存成立の判定階層

| 判定段階 | 合格条件 | 現在の結果 | 判定 |
|---|---|---|:---:|
| 静的成立性 | 3種すべてが正の共通増殖率を持つ | 現行培地0 h^-1、最大操作後0.0426 h^-1 | 条件付き合格 |
| 希少菌侵入スクリーニング | 各菌を0.001 g/Lにしても正の増殖解 | 3種とも0.0422 h^-1 | 予備合格 |
| 動的持続性 | 48 h後に全種>0.01 g/L、非負増殖、pH 4–9.5 | 現行最大操作はpH 2.21、全種−0.0895 h^-1 | 不合格 |
| PHA理論到達性 | 正の増殖制約下でPHAフラックス>0 | 最大10.0766 mmol/gDCW/h | 合格 |
| 共存＋PHA実現 | 同一dFBAで全種維持かつPHA>0 | オラクルでPHA 5.334 mmol | 条件付き合格 |
| RL可制御性 | 必要操作が行動、切替状態が観測に含まれる | pH操作なし、NH4観測なし | 不合格 |
| 長期・頑健性 | 168 h、初期比率、撹乱、seed反復で維持 | 未実施 | 未判定 |

ここで希少菌試験は、共有培地max–min LPにおける予備的な侵入可能性である。定常状態の
resident communityへ希少菌を導入する厳密な生態学的侵入試験ではない。

## 実測した対照

### 現行RLの最大操作

5操作を48時間すべて最大にした。3種の菌体は生存閾値以上に残ったが、全種が負の増殖に
転じ、PHAは生成されなかった。

| 指標 | 結果 |
|---|---:|
| 最終pH | 2.210 |
| OR16 | 0.4760 g/L |
| NS21 | 0.08477 g/L |
| L. plantarum | 0.03131 g/L |
| 全種の終点増殖率 | −0.08950 h^-1 |
| PHA | 0 mmol |
| ゴム残量 | 89.512 g/L |

菌体が残っているためエピソードは終了しないが、状態は安定共存ではなく酸性化後の衰退で
ある。1種だけが脱落しても終了しない現在の終了条件では、PPOが3種維持を必須条件として
学ぶ保証もない。

### 修正後の可解性を確認するオラクル対照

理想pH-statを追加し、0–12時間は最大給餌、その後は酵母エキスを止めて種別炭素源とKLaを
維持した。これによりNH4を枯渇させ、NS21を増殖目的からPHA目的へ切り替えた。

| 指標 | 結果 |
|---|---:|
| 最終pH | 6.973 |
| OR16 | 3.7477 g/L |
| NS21 | 0.5735 g/L |
| L. plantarum | 0.1287 g/L |
| 終点増殖率 | OR16 0.01315、NS21 0、LP 0 h^-1 |
| PHA | 5.334 mmol |
| 最終NH4 | 1.69×10^-5 mmol/L |
| 累積塩基需要 | 201.891 mmol/L |
| ゴム残量 | 73.284 g/L |

この結果は、修正後の制御問題がモデル上可解であることを示す。一方、理想pH-statと高い
塩基需要を仮定しているため、実験条件の妥当性を保証するものではない。

## 現行RL設計の問題

1. **pHは観測できるが操作できない。** 報酬で低pHを罰しても、行動空間に塩基滴定・
   buffer feedがないため、PPOは酸性化を直接修正できない。
2. **PHA切替状態が隠れている。** NS21はNH4<0.1 mmol/LでPHA目的へ切り替わるが、NH4は
   観測ベクトルに含まれない。
3. **炭素と窒素が結合している。** 酵母エキス操作は炭素、NH4、アミノ酸を固定比で同時に
   加える。共存維持のための給餌が窒素枯渇とPHA誘導を妨げる。
4. **培地律速を直接観測できない。** g3ps、isoleucine、主要有機酸は観測されない。
   最大操作ではmannitolと酵母エキスが代替レスキューになるが、どの成分が律速かを方策が
   識別できない。
5. **1種脱落が強い制約になっていない。** 終了条件は全種が0.01 g/L未満になった場合だけで、
   多様性ペナルティも1ステップ最大0.2と小さい。
6. **最大給餌が無コストである。** 給餌コストがなく、過剰給餌、酸生成、NH4維持へ向かう
   不適切な局所解を許す。
7. **48時間以降の安定性は未証明である。** 実際の学習コードは168時間エピソードなので、
   168時間、複数初期比率、摂動後回復を事前に通す必要がある。

## RL再開前の必須修正

### 行動空間

- 塩基滴定量またはpH setpointを独立した操作として追加する。
- 炭素源、窒素源、酵母エキスを分離する。
- 必要ならg3psまたは実験的に妥当な代替炭素源を独立操作にする。
- 各操作を「1ステップ当たり量」ではなく mmol/L/h に統一し、dt依存性を除く。

### 観測空間

- NH4、g3psまたは代替炭素源、isoleucine、主要有機酸、累積塩基量を追加する。
- PHA目的への切替状態を明示するか、NH4から一意に復元可能にする。

### 制約・報酬

- いずれか1種が閾値未満になったら終了、またはconstrained RLの制約違反とする。
- 終点だけでなく、最小菌体量、負の増殖率、pH逸脱時間を制約として記録する。
- PHA報酬と給餌・滴定コストを分け、過剰給餌を抑制する。

### 学習前ゲート

1. 決定論的二段階制御で168時間、全種>0.01 g/L、pH範囲内、PHA>0を満たす。
2. 各菌を初期0.001、0.01、0.1 g/Lに変えて侵入・回復を確認する。
3. 初期比率、培地濃度、モデル境界を±10–20%変えた感度解析を行う。
4. 上記を満たした後にのみPPO/SAC比較へ進む。

## 解釈上の注意

共有培地max–min LPはSteadyCom型のbalanced-growth screen、代謝物授受はMICOM型の協調的
community FBAを参考にした成立可能性評価である。正の共通増殖や予測授受は、実験的な
相利共生の証明ではない。長期継代、侵入可能性、撹乱後回復の実験が別途必要である。
